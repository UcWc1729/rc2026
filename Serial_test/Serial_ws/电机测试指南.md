# 🔄 持续发送测试 - 电机转动测试指南

## 🎯 目标
持续发送速度命令到下位机，测试电机是否能正常转动

## ⚡ 快速开始

### 方式1：一键启动（推荐新手）
```bash
./start_continuous_test.sh
```
- 自动检查串口权限
- 以50Hz频率持续发送 Vx=0.1 命令
- 按 Ctrl+C 停止（自动发送零速度停止电机）

### 方式2：交互式测试（推荐）🎮
```bash
python3 interactive_motor_test.py
```

**功能特点**：
```
📋 命令菜单:
  1 - 前进测试  (Vx=0.1)
  2 - 后退测试  (Vx=-0.1)
  3 - 左移测试  (Vy=0.1)
  4 - 右移测试  (Vy=-0.1)
  5 - 左转测试  (Wz=0.5)
  6 - 右转测试  (Wz=-0.5)
  7 - 自定义速度
  s - 开始/继续发送
  p - 暂停发送
  0 - 停止电机（零速度）
  q - 退出程序
```

**使用流程**：
1. 运行程序自动连接串口
2. 按 `1` 选择前进测试
3. 按 `s` 开始发送
4. 观察电机是否转动
5. 按 `p` 暂停或 `0` 停止电机
6. 按 `q` 退出

### 方式3：直接运行Python脚本
```bash
python3 continuous_send.py
```

## 🔧 修改速度参数

### 在continuous_send.py中修改
编辑文件，找到第90-93行：
```python
sender.vx = 0.1    # 前进速度 (m/s) - 改这里
sender.vy = 0.0    # 横向速度 (m/s) - 改这里
sender.wz = 0.0    # 旋转速度 (rad/s) - 改这里
sender.send_rate = 50  # 发送频率 (Hz) - 改这里
```

**建议测试速度**：
- 慢速测试：`vx = 0.05` (5cm/s)
- 正常速度：`vx = 0.1` (10cm/s)
- 快速测试：`vx = 0.5` (50cm/s)

## 🔍 验证电机转动

### 检查项目

#### 1. 数据发送正常
- ✅ 看到"已发送 XX 帧"持续增加
- ✅ 无发送失败错误
- ✅ 串口连接稳定

#### 2. 下位机接收正常
在STM32端添加调试输出：
```c
void handle_chassis_speed(float vx, float vy, float wz) {
    printf("收到速度: vx=%.2f, vy=%.2f, wz=%.2f\n", vx, vy, wz);
    
    // 检查数据正确性
    if (vx == 0.1f && vy == 0.0f && wz == 0.0f) {
        printf("✓ 数据正确！\n");
    }
}
```

#### 3. 电机控制正常
- ✅ 电机响应速度命令
- ✅ 转动方向正确
- ✅ 速度符合预期
- ✅ 停止命令有效

## 🐛 故障排除

### 问题1：电机不转动

**可能原因**：
1. 下位机未正确接收数据
   - 检查串口连接是否正常
   - 使用串口助手查看原始数据
   - 检查波特率是否匹配（115200）

2. 下位机未解析数据
   - 检查protocol_chassis.c是否正确集成
   - 添加调试输出查看接收情况
   - 验证CRC校验是否通过

3. 电机控制未生效
   - 检查电机驱动是否初始化
   - 验证PWM输出是否正常
   - 检查电机使能信号

### 问题2：发送速度慢

**解决方法**：
```python
sender.send_rate = 100  # 增加到100Hz
```

### 问题3：电机转动不平滑

**可能原因**：
- 发送频率太低（增加到50Hz以上）
- 串口通信延迟（检查缓冲区设置）
- 下位机处理慢（优化代码）

### 问题4：停止不灵敏

**解决方法**：
```python
# 修改停止时发送次数（在stop方法中）
for _ in range(10):  # 增加到10次
    self.send_speed()
    time.sleep(0.01)
```

## 🎯 测试建议

### 阶段1：基础测试
1. 使用 `Vx=0.05` 慢速测试
2. 确认电机能转动
3. 验证方向正确

### 阶段2：方向测试
使用交互式测试依次测试：
- 前进 (Vx > 0)
- 后退 (Vx < 0)
- 左移 (Vy > 0)
- 右移 (Vy < 0)
- 左转 (Wz > 0)
- 右转 (Wz < 0)

### 阶段3：速度测试
逐步增加速度：
- 0.05 m/s
- 0.1 m/s
- 0.2 m/s
- 0.5 m/s

### 阶段4：停止测试
- 测试急停响应时间
- 验证零速度命令有效
- 检查停止精度
