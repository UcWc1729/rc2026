# 🚀 底盘速度控制 - 快速命令

## 查看使用指南
```bash
./USAGE.sh
```

## 快速测试（6选1）

### 1️⃣ 简化版测试 🌟（最推荐 - 与诊断工具相同逻辑）
```bash
python3 simple_motor_test.py
```
**特点**：
- 主线程直接发送，稳定可靠
- 菜单选择，每次发送固定时长
- 与diagnose_serial.py使用相同逻辑
- **如果诊断工具能工作，这个一定能工作**

### 2️⃣ 一键测试（单次发送）
```bash
./quick_test.sh
```

### 3️⃣ 持续发送测试 ⭐（测试电机转动）
```bash
./start_continuous_test.sh
# 或直接运行
python3 continuous_send.py
```
**特点**：
- 以50Hz频率持续发送Vx=0.1速度命令
- 按Ctrl+C停止，自动发送零速度停止电机
- 实时显示发送状态

### 4️⃣ 交互式测试 🎮（功能强大但可能有线程问题）
```bash
python3 interactive_motor_test.py
```
**特点**：
- 菜单式操作，方便测试各个方向
- 可实时修改速度参数
- 支持前进/后退/左移/右移/旋转测试
- ⚠️ **注意**：如果不工作，请使用simple_motor_test.py

### 5️⃣ ROS2节点
```bash
./start_chassis_controller.sh
```

### 6️⃣ Python单次测试
```bash
python3 test_chassis_speed.py
```


## 发送自定义速度

### 1. 修改continuous_send.py中的速度（持续发送）
编辑文件第90-92行：
```python
sender.vx = 0.5    # 改成你想要的前进速度
sender.vy = 0.0    # 改成你想要的横向速度  
sender.wz = 0.0    # 改成你想要的旋转速度
```

### 2. 使用交互式测试（最简单）
```bash
python3 interactive_motor_test.py
# 然后按菜单选择：
# 1-前进 2-后退 3-左移 4-右移 5-左转 6-右转 7-自定义
```

### 3. 通过ROS2话题（单次发送）
```bash
# 前进 0.5 m/s
ros2 topic pub /cmd_vel geometry_msgs/msg/Twist "{linear: {x: 0.5}}"

# 全向移动: Vx=0.1, Vy=0.2, Wz=0.3
ros2 topic pub /cmd_vel geometry_msgs/msg/Twist \
  "{linear: {x: 0.1, y: 0.2}, angular: {z: 0.3}}"
```
