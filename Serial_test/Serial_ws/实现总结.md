## 📦 生成的数据帧分析

**命令**: Vx=0.1 m/s, Vy=0 m/s, Wz=0 rad/s

**完整帧数据**:
```
a5 0e00 00 bc 0101 cdcccc3d 00000000 00000000 7278
```

**详细解析**:
```
帧头部分 (5字节):
  A5          - SOF (起始标志)
  0E00        - 数据长度 14字节 (小端序: 0x000E)
  00          - 序列号 0
  BC          - CRC8校验值

数据部分 (14字节):
  0101        - 命令ID 0x0101 (CMD_CHASSIS_SPEED)
  CDCCCC3D    - vx = 0.1 (float, 小端序)
  00000000    - vy = 0.0 (float, 小端序)
  00000000    - wz = 0.0 (float, 小端序)

校验部分 (2字节):
  7278        - CRC16校验值 (小端序: 0x7872)
```

**总长度**: 21字节

## 🛠️ 下位机集成

将附件中的 `protocol_chassis.c` 和 `protocol_chassis.h` 添加到STM32项目：

```c
// 在main.c中
#include "protocol_chassis.h"

// 初始化
Protocol_Init();

// 注册回调
Protocol_Callbacks callbacks = {
    .on_chassis_speed = handle_chassis_speed,
    .on_chassis_stop = handle_chassis_stop,
    .on_heartbeat = handle_heartbeat
};
Protocol_RegisterCallbacks(&callbacks);

// UART接收回调
void HAL_UART_RxCpltCallback(UART_HandleTypeDef *huart) {
    if (huart == &huart6) {
        Protocol_ProcessData(rx_buffer, rx_length);
    }
}

// 速度控制回调
void handle_chassis_speed(float vx, float vy, float wz) {
    printf("Received speed: vx=%.2f, vy=%.2f, wz=%.2f\n", vx, vy, wz);
    // 控制电机
}
```
