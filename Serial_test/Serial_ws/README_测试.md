## 🔧 快速修改速度

### 方法1：交互式修改（推荐）
```bash
python3 interactive_motor_test.py
# 按 7 选择自定义速度
# 输入你想要的vx, vy, wz值
```

### 方法2：修改continuous_send.py
编辑第90-93行：
```python
sender.vx = 0.5    # 改成你想要的速度
sender.vy = 0.0
sender.wz = 0.0
sender.send_rate = 50  # 改成你想要的频率
```

## 📝 测试步骤（推荐）

1. **启动交互式测试**
   ```bash
   python3 interactive_motor_test.py
   ```

2. **选择测试方向**
   - 按 `1` 测试前进
   - 按 `2` 测试后退
   - 按 `3` 测试左移
   - ...

3. **开始发送**
   - 按 `s` 开始持续发送

4. **观察电机**
   - 检查电机是否转动
   - 验证转动方向

5. **停止测试**
   - 按 `0` 停止电机
   - 或按 `p` 暂停发送

6. **退出程序**
   - 按 `q` 退出
